# Data Cloud Mission — Connect the Data

A **6-level interactive learning game** about Salesforce Data 360 data connection and ingestion, built with plain HTML, CSS, and JavaScript.

## Live demo
After enabling GitHub Pages, put your GitHub Pages URL here.

## Run locally
Open `index.html` in a modern browser. No installation, accounts, credentials, dependencies, or backend required.

## Missions
1. Meet Data Cloud — platform purpose
2. Choose the Connector — source/connector matching
3. Build a Data Stream — order the steps
4. Explore DLOs — source data and Data Lake Objects
5. Zero-Copy Challenge — data federation
6. Manifest File Detective — file metadata

Features: score, hints, progress bar, unlockable levels, a final Explorer badge, and shareable achievement text.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `data-cloud-mission`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**. Select **Deploy from a branch**, **main**, and **/(root)**, then save.
4. Your site URL will typically be `https://YOUR-USERNAME.github.io/data-cloud-mission/` (replace YOUR-USERNAME).

## Notes
This is a conceptual educational simulation, **not** a real Salesforce org integration. Details of connectors, federation, and file manifests depend on supported capabilities and configuration. It is not affiliated with or endorsed by Salesforce.
